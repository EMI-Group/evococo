# Generated Algorithms

This directory contains the 48 original tensorized implementations generated with the EvoMO 0.2.1
API. The WFG problems used in the experiments were later released with EvoMO 0.2.2.

EvoMO 0.2.2 added a fifth return value to `nd_environmental_selection`. Some files may therefore
require API adaptation when used with EvoMO 0.2.2 or later; the generated artifacts remain unchanged.
